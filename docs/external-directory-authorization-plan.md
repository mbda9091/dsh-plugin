# 工作区外写入审批方案（已撤销）

2026-11-06 按用户决定移除 approval-allowlist 插件。此前的自动审批、持久授权规则、管理工具与真实宿主探针均不再由本仓库提供；源码、模板和专属测试已删除。历史方案和验收记录可从 Git 历史查阅，不能作为当前能力说明或交付证据。

审批和沙箱边界继续由宿主负责。独立的目录扩展设计见 [沙箱目录扩展方案](sandbox-directory-extension-plan.md)。

本次删除只涉及仓库，不自动卸载用户已有 profile 中的插件，也不删除授权文件或个人配置。已安装环境应通过宿主支持的方式停用并处理旧 bundle；不得使用 pnpm remove 删除 link 依赖，以免跟随链接删除源码。
