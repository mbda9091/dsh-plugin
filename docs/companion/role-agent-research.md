# 持续成长的角色 Agent：调研依据

更新：2026-11-14；研究核对日期保留为 2026-11-13。状态：已有研究记录，未复现，不构成系统选型结论。

**本文只维护“有什么证据、证明了什么、对我们有什么启发”。** 产品目标和能力边界见[总体设计](role-agent-design.md)，首轮实现与试验见[初步落地](role-agent-initial-plan.md)。新增论文或修正证据时优先只改本文；改变产品目标需另行修改总体设计。

## 1. 范围与证据边界

本轮从游戏厂商及合作团队入手，追踪角色构建、自主行动、长期演化和会话评估，补充直接研究人格成长的学术工作。依据作者论文、正式论文集及官方项目介绍；不是系统性文献综述，也未复现代码或开展真人长期实验。

以下分别记录上游方法、实际证据与本项目推论。2026 年研究不因更新而自动优于早期工作；演示、模拟轨迹、真人游戏反馈也不能互相替代。网页与未固定的项目实现可能继续变化。

## 2. 研究条目

### 2.1 微软研究院 × Xbox：VEGA

来源：[官方项目介绍](https://www.microsoft.com/en-us/research/project/project-vega/)。证据类型：项目介绍与原型演示；本轮未取得足以复现长期成长机制的公开论文细节。

- 初始 Soul 引导角色的视角、目标和响应方式；角色通过活动积累记忆与技能，并形成关系。
- 玩家用自然语言影响角色；角色可以解释、询问，或抵触与自身身份冲突的请求。
- 官方探索玩家离开后角色继续活动；相似的初始角色可因不同经历向不同方向发展。
- **本项目启发**：体验目标是共同生活与发展，不能只设计被动应答；Soul 是起点，后续经历也应塑造角色。
- **边界**：愿景和演示不证明数月尺度的人格成长已经成立。

### 2.2 港科大、LIGHTSPEED 等：EvolvingWorld，2026

来源：[论文 v1 与方法正文](https://arxiv.org/html/2607.17250v1)、[正式论文集](https://aclanthology.org/2026.findings-emnlp.1366/)。本轮方法记录以 arXiv v1 为准，不宣称逐项核对最终发表版差异。

- 角色与世界状态持续更新，角色使用开放字段的 profile；不同维度具有不同变化速度。
- hidden tracker 暂存弱信号，避免轻微或模糊事件立即改变人格；积累证据后再判断更新。
- 评价变化是否有事件依据、幅度是否匹配、轨迹是否平滑，并检查角色与场景连续性。
- **本项目启发**：设置变化证据与不同时间尺度，区分即时情绪和持久变化；先积累信号，再判断是否成长。
- **边界**：实验是文学世界模拟，最多 20 场景、每场景最多 50 次交互；轨迹评估主要采用模型裁判并辅以人工核对，不能外推为与真人相处数月的验证。

### 2.3 同济大学：Evolving Agents，2024

来源：[论文 v1](https://arxiv.org/html/2404.02718v1)。证据类型：预印本中的模拟实验及人的可信度评价。

- 人格系统包含认知、情绪和角色成长；行为系统包含计划和行动。
- 角色成长依次更新状态、特征、内在矛盾和偏好，主要依赖提示词及自然语言状态。
- 十个 Agent 的模拟中包含消融与人的评价，研究行为和人格变化的可感知性及可信度。
- **本项目启发**：经历需经角色自己的认知与情绪解释，才能形成差异化成长，并反馈到行为。
- **边界**：短期模拟与可信度评价不能证明长期一对一关系可靠，也不证明该架构等同于人的心理机制。

### 2.4 腾讯天美与曼彻斯特大学等：SimsChat，2024／2025

来源：[作者论文](https://arxiv.org/abs/2406.17962)、[EMNLP 2025 论文](https://aclanthology.org/2025.findings-emnlp.1100.pdf)。

- 从职业、抱负、特质和技能扩展个人背景与社会关系，在不同场景、情绪和话题下构建互动。
- SimsConv 包含 68 个角色、1,360 个场景和 13,971 段多轮对话；主要研究可定制角色与扮演一致性。
- **本项目启发**：初始角色应包含目标、能力、犹豫、自我理解及未解决的矛盾，为后续发展提供选择依据。后一句是设计推论。
- **边界**：角色构建与一致性不等于人格长期成长。

### 2.5 网易伏羲、浙江大学等：DynSess，2026

来源：[论文 v1](https://arxiv.org/html/2605.29256v1)。证据类型：论文中的会话级评价与训练实验。

- 将角色扮演作为会话级任务，用完整对话评分，避免只看单轮表现。
- 通过会话级奖励构建训练轨迹并优化模型；作者报告评价与人的判断更一致。
- **本项目启发**：持续观察角色选择、关系变化和互动质量，不能用语气一致或记住称呼代替长期评价。
- **边界**：会话级优化不直接证明跨月人格成长；本轮未复现训练和评分。

### 2.6 KRAFTON：PUBG Ally，2026

来源：[论文 v1](https://arxiv.org/html/2609.29837v1)。证据类型：系统论文、真人游戏数据与限时线上测试反馈。

- 将语音、记忆、高层决策与快速游戏控制结合，报告接近 3.9 万次真人游戏会话的数据。
- 展示跨局保留玩家偏好，在相关情境下主动执行；也报告记忆不一致、旧目标持续过久等失败。
- **本项目启发**：共同经历的价值应在恰当行动中体现，例如在后来相关情境中履行约定；评价应结合真实互动反馈。
- **边界**：跨局记忆与协作不等于人格成长，展示的成功案例不代表每次均成功。

### 2.7 对照方向：AutoPal

来源：[论文 v3](https://arxiv.org/html/2406.13960v3)。团队包括香港理工大学、腾讯优图与百度；作为个性化陪伴研究对照，不归为游戏厂商落地证据。

- 根据用户信息调整 Agent 人格，锁定已表达过的属性，检查新属性兼容性，并定期整理 profile。
- **可参考**：更新前检查矛盾，保护角色连续性。
- **需区分**：适配用户期待不等于保有自身立场的成长。“越来越懂用户”与“越来越接近用户偏好的形象”应分别评价，不能以取悦用户作为成长的唯一目标。

## 3. 证据如何影响设计

| 研究线索 | 可以启发的能力 | 不能直接推出的实现决定 |
|---|---|---|
| VEGA | 自身动机、共同活动、经历连续性 | 必须有后台世界或多 Agent 社会 |
| EvolvingWorld | 不同变化速度、证据积累、演化轨迹评价 | 必须使用独立候选服务、固定心理阈值 |
| Evolving Agents | 认知、情绪、成长影响行为的循环 | 每轮必须分开调用评价模型与回复模型 |
| SimsChat | 初始角色的动机、能力与社会背景 | 写好初始角色就解决了长期成长 |
| DynSess | 评价连续会话，而非只看单轮 | 会话评分等同于跨月成长验证 |
| PUBG Ally | 记忆在相关行动中体现，与真实反馈对齐 | 跨次偏好记忆就等于人格演化 |
| AutoPal | 检查新旧认识的兼容性 | 向用户偏好靠拢就是我们的成长目标 |

十四模块分解、四项落地职责及复盘更新流程均为本项目工程提案；没有一篇上述资料验证它们的整体组合效果。后续应同时记录支持结果与失败结果，不能把来源数量当作架构有效性。
